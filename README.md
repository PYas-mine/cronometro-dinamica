# Cronômetro

Esse repositório usa a ideia de cronômetro decrescente com duas possibilidades nos cantos superiores: música temática Cyberpunk que acompanha os 40 minutos da dinâmica e alarme sonoro que deve ser ativado por clique.
A dinâmica é um Escape Room Cyberpunk com diversos desafios, porém o cronômetro pode ser utilizado em outros momentos pedagógicos.

Esse projeto utiliza linguagem HTML, CSS e JavaScript
